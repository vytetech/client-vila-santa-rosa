# Security Policy

## Como reportar vulnerabilidades / Reporting vulnerabilities

**Não publique vulnerabilidades exploráveis, credenciais ou dados privados em issues públicas.**

Envie um relato privado para [contato@vytetech.com](mailto:contato@vytetech.com) com o assunto `Security report — GitHub`. Inclua o nome do repositório, o possível impacto e passos de reprodução seguros.

**EN:** Please do not disclose exploitable issues, customer data or credentials in public issues. Report privately to the email above, including the repository name and reproduction details.

## Escopo de suporte

Suporte, manutenção e correções dependem do contrato do projeto. Esta política não cria garantia de prazo de resposta nem programa de recompensas.

Não utilize dados reais de clientes nem ambientes de produção para provas de conceito sem autorização explícita.
